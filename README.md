# Title Capitalizer Plugin for OJS/OMP 3.4

This plugin adds an "aA" button next to Title and Subtitle fields in OJS and OMP 3.4. Clicking the button automatically capitalizes the text according to the selected style.

## Features

- **One-Click Capitalization**: Adds a dedicated button next to metadata title fields.
- **Multiple Styles**: Supports Chicago (Title Case), APA, MLA, Sentence case, ALL CAPS, and lowercase.
- **Configurable**: Choose your preferred default style in the plugin settings.
- **Quick Submit Support**: Works seamlessly with the Quick Submit plugin.
- **Safe Editing**: Allows manual corrections after auto-capitalization (e.g., for acronyms).

## Installation

1. Upload the `titleCapitalizer` directory to your OJS/OMP `plugins/generic/` folder.
2. Log in as an administrator.
3. Go to **Settings > Website > Plugins**.
4. Find **Title Capitalizer** under the Generic Plugins list and enable it.
5. Click **Settings** to choose your preferred capitalization style.

## Supported Pages

- Submission Wizard (Metadata step)
- Article/Monograph Metadata Edit pages
- Quick Submit plugin submission form
